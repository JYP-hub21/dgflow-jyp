DG-Flow 방문 시연 진행 계획
동일유리(주) 방문 · 소개 및 시연 · 60분

1. 이 자리의 목적

성격시스템 소개 + 실제 화면 시연 (겸용)
참석경영진·임원 / 공사관리부 / 경영지원팀
시간60분 — 소개 15분, 시연 25분, 질의응답 10분, 마무리 5분, 여유 5분
달성 목표 ① 실사용자가 직접 보고 “우리 방식과 다른 점”을 지적하게 한다
② 병행 운영 시작 시점과 대상 현장을 합의한다
③ 팀별 실사용 담당자를 지정받는다
진행 원칙
이 자리는 완성품 검수가 아니라 요구사항 수집입니다. 매끄럽게 끝내는 것보다 지적을 많이 받는 편이 성공입니다. 시연 중 참석자가 말을 끊으면 반기고, 그 자리에서 메모합니다. 반박하지 않습니다. “그건 이미 됩니다”라고 답하고 싶은 순간이 와도, 먼저 어떻게 하고 계신지 되묻는 편이 낫습니다.

3. 시연 시나리오

주문 한 건을 접수부터 생산 지시까지 끝까지 따라갑니다. 역할이 바뀔 때마다 로그아웃 후 다른 계정으로 로그인합니다. 브라우저 탭을 역할별로 미리 열어두면 전환이 빨라집니다.

#계정조작말할 것 · 보여줄 것
1공사관리부
ahn@		 주문 > 새 주문 > 실제 발주서 엑셀 업로드 > 자동 채워진 품목 확인 > 저장 가장 중요한 장면. 파일을 고르는 순간부터 품목 표가 채워질 때까지 말을 멈추고 화면만 보게 합니다.
“양식을 바꾸시라는 게 아닙니다. 쓰시던 걸 그대로 올리시면 됩니다.”
2공사관리부 주문 상세 > 주문의뢰서 미리보기 > 인쇄 화면 기존 종이 양식과 같은 모양임을 확인시킵니다. 결재란에 이름이 자동으로 들어간 것을 짚습니다.
3고객 외부 승인 요청 > 링크 복사 > 시크릿 창에 붙여넣기 > 승인 반드시 시크릿 창을 씁니다. 로그인 없이 열리는 것이 핵심이기 때문입니다.
“고객은 계정을 만들 필요가 없습니다. 링크만 누르면 됩니다.”
4경영지원팀
support@		 검토 > 검토 시작 > 검토 완료 > ERP 엑셀 다운로드 > 파일 열기 이지원 님이 가장 관심 있을 장면. 다운로드한 엑셀을 실제로 열어서 16열 양식과 품명 변환 결과를 보여줍니다.
“표준 양식으로 다시 만드시는 작업이 이 버튼 하나로 대체됩니다.”
5관리자
admin@		 승인 > 최종 승인 > 작업의뢰서 자동 생성 확인 버튼 하나로 작업의뢰서가 생기는 순간을 강조합니다. 의뢰번호가 자동 채번된 것을 짚습니다.
6생산관리팀
production@		 생산 > 작업의뢰서 > 실적 일괄 입력 > 진행률 확인 생산관리팀 미참석이므로 짧게. 진행률 막대가 움직이는 것만 보여주고 넘어갑니다.
7관리자 대시보드 > 방금 만든 주문이 반영된 모습 마무리. 경영진 대상 메시지.
“방금 만든 주문 한 건이 이 화면에 바로 올라옵니다. 전화로 물어보실 일이 없습니다.”

4. 사전 준비 — 방문 전날까지

⚠ 가장 중요 — 시연용 데이터가 지금 비어 있습니다
현재 운영 DB의 주문 건수는 0건입니다. 이 상태로 대시보드를 열면 그래프도 목록도 전부 비어 있어 시연의 설득력이 크게 떨어집니다. 방문 전에 반드시 현실적인 샘플 주문 15~20건을 (다양한 상태·거래처·납기로) 넣어두어야 합니다. 거래처·현장·품명 기준정보는 이미 들어가 있으므로 주문 데이터만 채우면 됩니다.

준비물 체크리스트

  • 시연용 샘플 주문 15~20건 투입 — 상태를 골고루 섞어 대시보드가 채워지게 (필수)
  • 실제 발주서 엑셀 파일 — 시연 1단계용. 참석자에게 익숙한 현장 것으로 고를 것
  • 노트북 + 충전기 + HDMI 어댑터 — 회의실 화면 연결 방식 사전 확인
  • 인터넷 회선 확인 — 동일유리 회의실 Wi-Fi 접속 가능 여부. 불가 시 휴대폰 테더링 준비
  • 브라우저 탭 5개 미리 로그인 — 공사관리부/경영지원팀/관리자/생산관리팀 + 시크릿 창
  • 글자 크기 확대 — 브라우저 확대 125~150%. 뒷자리에서 표가 읽혀야 함
  • 알림·메신저 끄기 — 화면 공유 중 개인 알림이 뜨지 않도록
  • 인쇄물 — 발표자료 참석 인원수 + 2부, 진행 계획서 1부(본인용)
  • 시연 리허설 1회 — 처음부터 끝까지 시간을 재면서. 25분 안에 끝나는지 확인

5. 문제가 생겼을 때

상황즉시 조치사전 대비
인터넷이 안 됨휴대폰 테더링으로 전환테더링 미리 테스트. 노트북에서 로컬 실행(npm run dev)도 가능하도록 준비
엑셀 업로드가 실패당황하지 말고 수동 입력으로 전환. “이 양식은 아직 학습이 안 됐습니다, 가져가서 반영하겠습니다”시연용 파일은 반드시 사전에 성공을 확인한 것만 사용
화면이 느림말로 채우며 기다림. 새로고침 반복 금지회의 직전 각 화면을 한 번씩 열어 예열
답 못 할 질문“확인해서 알려드리겠습니다” + 그 자리에서 메모모르는 것을 아는 척하지 않는다. 신뢰가 더 중요
부정적 반응방어하지 말고 구체적으로 더 물어본다. “지금은 어떻게 하고 계신가요?”반대 의견이 가장 값진 수확이라는 점을 미리 마음에 새길 것

6. 예상 질문과 답변

질문답변 방향
기존 엑셀을 계속 써도 되나?됩니다. 오히려 그게 전제입니다. 쓰시던 엑셀을 올리면 시스템이 읽습니다. 양식 통일을 요구하지 않습니다.
인터넷이 끊기면 일을 못 하나?웹 시스템이라 접속은 필요합니다. 다만 기존 엑셀 방식이 사라지는 게 아니므로, 병행 운영 기간에는 문제가 되지 않습니다.
기존 ERP는 어떻게 되나?그대로 쓰십니다. DG-Flow는 ERP에 넣을 엑셀을 자동으로 만들어 주는 역할입니다. ERP를 바꾸자는 게 아닙니다.
고객이 링크를 안 누르면?기존처럼 전화·메일로 확인하시고 담당자가 대신 처리할 수 있습니다. 링크는 편의 수단이지 강제가 아닙니다.
데이터가 밖으로 새지 않나?로그인한 사람만 접근합니다. 고객 승인 링크는 해당 주문 하나에만 연결되고 기한이 지나면 만료됩니다. 모든 변경은 기록이 남습니다.
지금 당장 쓸 수 있나?기능은 완성돼 있습니다. 다만 실제 발주서로 검증한 기간이 짧아, 기존 방식과 병행하며 한 달 정도 다듬는 것을 권합니다.
쓰다가 문제가 생기면?연락 주시면 수정합니다. 웹 시스템이라 고치면 즉시 모든 분께 반영됩니다. 각자 PC에 다시 설치할 필요가 없습니다.
비용이 드나?현재 무료 범위에서 운영 중입니다. 사용량이 늘면 그때 실제 수치로 다시 말씀드리겠습니다.
우리 양식이 인식이 안 되면?파일을 주시면 그 양식을 읽도록 추가합니다. 지금까지 6종을 그렇게 늘려 왔습니다.
직원들이 쓰기 어려워하면?화면 수를 일부러 줄였습니다. 역할별로 필요한 메뉴만 보입니다. 필요하면 팀별 30분 교육을 따로 하겠습니다.
