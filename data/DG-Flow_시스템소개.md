# DG-Flow 시스템 소개

## 동일유리 주문관리 시스템

> 동일유리(주) & 충북대학교 RISE AX기업혁신 공동연구과제
> 2026년 9월

---

## 1. 왜 DG-Flow가 필요한가?

### 현재 업무의 문제점

동일유리의 주문 처리 과정에서 다음과 같은 비효율이 반복적으로 발생하고 있습니다.

#### 문제 1: 양식 비표준화
공사관리부 담당자마다 **서로 다른 엑셀 양식**을 사용하고 있습니다.

| 담당자 | 양식 특징 | 시트 수 |
|--------|----------|--------|
| 안광식 상무 | 골조도 기반 + 물량산출서 + 차수별 발주 | 17개 시트 |
| 이충언 이사 | 타입별 주문내역 (EA 단위) | 3개 시트 |
| 김길홍 과장 | 발주번호 체계, 규격 병합 셀 | 1개 시트 |
| 오동석 부장 | 날짜+내용별 세분화 | 32개 시트 |
| 대진글라스 | 골조도 + 동호수 배치도 | 6개 시트 |
| 정석개발 | 생산의뢰서 대량 데이터 | 1개 시트 (484행) |

#### 문제 2: 이중 변환
```
고객 → (이메일/엑셀/카톡) → 공사관리부 → (각자 다른 엑셀) → 경영지원팀 → (표준화) → ERP
```
동일한 데이터를 **3번 가공**합니다. 공사관리부가 엑셀을 만들고, 경영지원팀이 다시 표준 양식으로 변환하고, ERP에 입력합니다.

#### 문제 3: 데이터 오류
수작업 변환 과정에서 **품명, 규격, 수량 오류**가 발생할 수 있습니다.
- 발주서 표기: `5CL/0.76PVB/5CL+10ALC+6EMT178`
- ERP 표기: `26.76T 10.76투명접합+10A+6로이`
- 이 변환을 사람이 매번 수작업으로 합니다

#### 문제 4: 모니터링 불가
주문서가 지금 어디에 있는지, 승인이 됐는지, 생산은 얼마나 진행됐는지 **아무도 실시간으로 확인할 수 없습니다.** 확인하려면 유선이나 메신저로 개별 문의해야 합니다.

#### 문제 5: 생산실적 수작업
생산관리팀이 작업의뢰서에 **수기로 생산 완료 수량을 표시**하고, 이를 다시 **엑셀에 수작업으로 입력**합니다.

## 2. DG-Flow란?

**DG-Flow (Dongil Glass Flow)**는 주문에서 생산까지의 **전체 업무 프로세스를 하나의 웹 시스템**으로 통합한 주문관리 시스템입니다.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| **단일 입력** | 공사관리부가 웹에서 표준화된 방식으로 한 번만 입력합니다. 기존 엑셀 발주서를 업로드하면 자동으로 데이터가 채워집니다. |
| **자동 변환** | 입력된 데이터가 자동으로 ERP 엑셀(16열)로 변환됩니다. 품명 변환, 규격 그룹핑, 주문번호 채번이 모두 자동입니다. |
| **승인 체인** | 고객→경영지원팀→관리자 단계별 승인이 디지털로 관리됩니다. 고객은 링크 클릭만으로 승인할 수 있습니다. |
| **실시간 모니터링** | 모든 이해관계자가 주문 상태, 생산 진행률, 납기 현황을 실시간으로 확인할 수 있습니다. |

### 한눈에 보는 변화

| 구분 | AS-IS (현재) | TO-BE (DG-Flow) |
|------|-------------|-----------------|
| 양식 | 담당자별 6종 이상의 엑셀 | 웹 표준 입력 폼 + 엑셀 자동 파싱 |
| 데이터 변환 | 경영지원팀 수작업 표준화 | 입력 시점에 표준화, ERP 엑셀 자동 생성 |
| 승인 | 유선/메신저 비공식 확인 | 4단계 디지털 워크플로우 + 이력 추적 |
| 모니터링 | 개별 문의 필요 | 실시간 대시보드 + 자동 알림 |
| 생산실적 | 수기 작성 → 엑셀 입력 | 웹 일괄 입력 + 일별 자동 집계 |
| ERP 입력 | 수작업 엑셀 가공 후 import | 자동 생성 후 다운로드 |

## 3. 주문 처리 흐름 (14단계)

DG-Flow에서 하나의 주문이 처리되는 전체 흐름입니다.

```
[공사관리부]                    [고객]                [경영지원팀]         [관리자]            [생산관리팀]
    │                            │                      │                  │                  │
    ├─ ① 주문 작성 (직접/엑셀)    │                      │                  │                  │
    ├─ ② 작성 완료               │                      │                  │                  │
    ├─ ③ 고객에게 승인 요청 ─────→│                      │                  │                  │
    │                            ├─ ④ 승인/반려          │                  │                  │
    │   (반려 시 ⑤ 수정→재전송)   │                      │                  │                  │
    │                            │──── 승인 ────────────→│                  │                  │
    │                            │                      ├─ ⑥ 검토 시작      │                  │
    │                            │                      ├─ ⑦ 검토 완료 ────→│                  │
    │                            │                      │                  ├─ ⑧ 최종 승인      │
    │                            │                      │                  │  (작업의뢰서 자동)  │
    │                            │                      │  ERP 엑셀 다운 ←─┤                  │
    │                            │                      │                  │─────────────────→│
    │                            │                      │                  │                  ├─ ⑨ 생산
    │                            │                      │                  │                  ├─ ⑩ 완료
    │                            │                      │                  │                  │
    ├─ 모니터링 ←───────────────────────────────────────────────────────────────────────────────┤
```

### 각 단계 상세

| 단계 | 상태 | 담당 | 설명 |
|------|------|------|------|
| ① | 작성중 | 공사관리부 | 주문 정보 입력. 엑셀 발주서 업로드 시 자동 채움. 여러 번 저장 가능 |
| ② | 작성완료 | 공사관리부 | 작성 완료. 이 상태에서 고객 전송 가능. 수정도 가능 (작성중으로 복귀) |
| ③ | 고객승인대기 | 고객 | 고객에게 승인 링크 전송. 전송 취소 가능 |
| ④ | 고객승인완료 | - | 고객이 승인. 경영지원팀 검토 대기. 반려 시 수정 후 재전송 |
| ⑤ | 반려-수정중 | 공사관리부 | 고객이 반려한 주문. 수정 후 다시 전송 |
| ⑥ | 검토중 | 경영지원팀 | 경영지원팀이 데이터 검토 |
| ⑦ | 검토완료 | 경영지원팀 | 검토 완료. 관리자 승인 대기 |
| ⑧ | 최종승인 | 관리자 | 관리자 승인 → **작업의뢰서 자동 생성** (1클릭). 승인 취소도 가능 |
| ⑨ | 생산중 | 생산관리팀 | 복층/재단 생산실적 입력 |
| ⑩ | 생산완료 | - | 전체 생산 완료 |

**핵심:** 관리자가 "최종 승인" 버튼 하나만 누르면 작업의뢰서가 자동으로 생성됩니다. ERP 엑셀은 승인 이후 언제든 별도로 다운로드할 수 있습니다.

## 4. 역할별 기능

### 공사관리부 (안광식, 이충언, 김길홍, 오동석)

- **주문 생성:** 거래처 선택 → 현장 선택 → 품목 입력 → 초안 저장
- **엑셀 발주서 업로드:** 기존 엑셀 파일을 업로드하면 기본정보(거래처, 현장, 날짜)와 품목이 자동으로 채워집니다
- **주문 수정/삭제:** 본인이 만든 주문만 수정/삭제 가능 (다른 담당자의 주문은 조회만)
- **고객 승인 요청:** 작성 완료 후 승인 링크를 생성하여 카카오톡/이메일로 전달
- **전송 취소:** 고객이 아직 응답하지 않았다면 전송을 취소하고 수정할 수 있음
- **생산 현황 조회:** 본인이 만든 주문의 생산 진행률을 확인

### 경영지원팀 (이지원)

- **주문 검토:** 고객이 승인한 주문의 데이터 검토
- **주문 수정:** 필요 시 데이터 보완/수정
- **검토 완료:** 검토 완료 후 관리자 승인 단계로 전달
- **ERP 엑셀 다운로드:** 최종 승인된 주문의 ERP 16열 엑셀을 다운로드
- **마스터 관리:** 품명, 거래처, 현장, 원판 마스터 데이터 관리

### 관리자/경영진 (김경영)

- **최종 승인:** 검토 완료된 주문을 승인 → 작업의뢰서 자동 생성
- **반려:** 문제가 있으면 반려 (경영지원팀이 재검토)
- **승인 취소:** 이미 승인한 건도 취소 가능
- **대시보드:** 전체 주문 현황, 납기 임박, 거래처별 통계, 추이 차트 확인
- **알림:** 승인 대기 건이 있으면 자동 알림

### 생산관리팀 (최생산)

- **작업의뢰서 확인:** 생성된 작업의뢰서 목록 및 상세 확인
- **복층 생산실적 입력:** 품목별 생산량을 한번에 입력 → [전체 저장]으로 일괄 처리
- **전량 완료:** 미완료 품목 전체를 한번에 완료 처리
- **재단실적 입력:** 원판 종류/수량, 오도시 구분, 주/야간 구분
- **일별 생산 이력:** 날짜별 생산 수량, 면적, 호기 자동 집계

## 5. 주요 화면 안내

### 5.1 로그인

- 웹 브라우저에서 접속 (PC, 태블릿, 모바일)
- 이메일 + 비밀번호 로그인
- 역할에 따라 사이드바 메뉴가 다르게 표시됨

### 5.2 주문 생성

**방법 1: 직접 입력**
1. [새 주문] 버튼 클릭
2. 거래처 선택 → 현장 자동 로드 → 주문일/납품일 입력
3. 품목 추가: 품명 선택 → 가로/세로(mm) → 수량 → 면적 자동 계산
4. [초안 저장]

**방법 2: 엑셀 발주서 업로드 (추천)**
1. [새 주문] 페이지 상단의 [기존 엑셀 발주서 업로드] 클릭
2. 기존에 사용하던 엑셀 파일 선택
3. 기본정보(거래처, 현장, 날짜)와 품목이 **자동으로 채워짐**
4. 필요 시 수정 후 [초안 저장]

**지원하는 엑셀 양식:**
- 김길홍 과장 양식 (30건 파싱 확인)
- 이충언 이사 양식 (13건 파싱 확인)
- 오동석 부장 양식 (107건 파싱 확인)
- 정석개발 양식 (48건 파싱 확인)
- 안광식 상무 양식 (394건 파싱 확인)
- 대진글라스 양식 (120건 파싱 확인)

### 5.3 고객 승인

1. 공사관리부가 [작성 완료] → [고객에게 승인 요청] 클릭
2. **승인 링크**가 생성됨 (파란색 카드로 표시)
3. [복사] 버튼으로 링크를 복사하여 카카오톡이나 이메일로 전달
4. 고객은 **로그인 없이** 링크를 클릭하여:
   - 주문의뢰서 내용 확인 (품목, 규격, 수량, 면적)
   - 결재란 확인 (작성자 이름 표시)
   - [승인] 또는 [반려] + 의견 입력
5. 승인/반려 결과가 공사관리부에 **자동 알림**

**링크 유효기간:** 7일 (만료 시 재발급 필요)

### 5.4 주문의뢰서

- 표준 양식으로 미리보기
- **결재란:** 작성(작성자) | 검토(경영지원팀) | 승인(관리자) — 각 단계 처리 시 자동으로 이름이 채워짐
- 품명별 소계 + 전체 합계
- [엑셀 다운로드] [인쇄] 가능

### 5.5 ERP 엑셀

- 최종 승인 이후 언제든 다운로드 가능
- **16열 양식:** 주문번호, 주문일자, 납품일자, 거래처, 현장명, 구분(TP), 품명, 두께, 가로규격, 세로규격, 주문수량, 출고수량, 잔여수량, 면적, 미출고액, 비고
- **규격 그룹핑:** 동일 품명+규격 자동 묶음 (라인 통합: 1~3, 타입 통합: 59A,B)
- **주문번호 자동 채번:** YYMMDD-일련번호 (예: 260825-01)

### 5.6 대시보드 (관리자)

- **요약 카드:** 전체 주문 건수, 처리 대기 건수, 이번달 수량, 이번달 면적
- **상태 파이프라인:** 14개 상태별 현재 건수
- **30일 추이 차트:** 일별 주문 건수 + 면적 바 차트
- **납기 임박:** D-7 이내 납기 주문 목록
- **거래처 Top5:** 주문 건수/수량/면적 순위
- **최근 주문:** 최근 5건 바로가기

### 5.7 작업의뢰서 상세

- **전체 진행률 바:** 의뢰수량 대비 완료수량 (%)
- **품목별 현황:** 각 품목의 의뢰/완료/잔여 수량 + 개별 진행률 바
- **복층 생산 이력:** 날짜, 수량, 면적, 주/야간, 호기, 작업자
- **재단 이력:** 날짜, 품명, 수량, 원판종류/수량, 오도시 표시
- **바로가기:** [복층 생산 입력] [재단 입력] [ERP 엑셀]

### 5.8 생산실적 입력

1. 상단에서 **생산일자, 주/야간, 호기(1호기/2호기)** 선택
2. 각 품목에 생산량 입력 (숫자만 입력)
3. **[전체 저장]** 버튼으로 입력된 모든 품목 일괄 저장
4. 또는 **[미완료 N건 전량완료]** 버튼으로 잔여 수량 전부 처리
5. 하단에 **일별 생산 이력** 자동 표시 (날짜, 수량, 면적, 건수, 구분)

### 5.9 알림

- 상태 변경 시 관련 담당자에게 **자동 알림** 생성
  - 고객 승인/반려 → 공사관리부에 알림
  - 검토 완료 → 관리자에 알림
  - 최종 승인 → 경영지원팀, 공사관리부, 생산관리팀에 알림
- 사이드바 상단 **벨 아이콘**에 안읽은 알림 수 표시
- 클릭하면 드롭다운으로 최근 알림 표시
- [전체 보기]로 전체 알림 목록 페이지 이동
- 30초마다 자동 갱신

## 10. 자주 묻는 질문

### Q: 기존 엑셀 파일을 계속 사용할 수 있나요?
**A:** 네. 기존 엑셀 발주서를 그대로 업로드하면 데이터가 자동으로 채워집니다. 6종의 양식을 모두 지원합니다. 다만 웹에서 직접 입력하는 것이 더 정확하고 빠릅니다.

### Q: 모바일에서도 사용할 수 있나요?
**A:** 네. 웹 브라우저만 있으면 됩니다. 스마트폰, 태블릿에서도 접속 가능합니다.

### Q: 고객이 별도의 앱을 설치해야 하나요?
**A:** 아니요. 고객은 링크 클릭만으로 승인할 수 있습니다. 앱 설치, 회원가입, 로그인 모두 불필요합니다.

### Q: 기존 ERP(바이투)와 어떻게 연동하나요?
**A:** ERP 엑셀 양식(16열)을 자동으로 생성합니다. 이 엑셀을 다운로드하여 기존과 동일하게 ERP에 import하면 됩니다.

### Q: 데이터는 안전한가요?
**A:** Supabase 클라우드에 저장되며, 로그인 인증 + 역할별 접근 제어 + 데이터 격리(RLS)가 적용되어 있습니다. 본인 주문만 수정/삭제 가능합니다.

### Q: 다른 담당자의 주문을 볼 수 있나요?
**A:** 조회는 가능하지만, 수정/삭제는 본인이 만든 주문만 할 수 있습니다.
